App User Flow: Armor Builder
1. Landing Page
	• Brief explanation of the Armor Building Complex
	• Call-to-Action (CTA): “Start Tracking Now”
	• Optional: “Learn More” link to program details
2. Session Setup (New Workout Screen)
	• Input kettlebell weight(s)
	• Set target number of rounds (optional)
	• Option to add session notes (optional)
	• Start Workout button
3. Workout Logging Screen
	• Display the Armor Building Complex structure:
		○ 2 Kettlebell Cleans
		○ 1 Kettlebell Press
		○ 3 Kettlebell Front Squats
	• Input field or quick-add button to log each completed round
	• Display:
		○ Current round count
		○ Kettlebell weight(s)
		○ Optional rest timer
	• Option to pause, edit, or discard session
4. Session Summary Screen
	• Show:
		○ Total rounds completed
		○ Kettlebell weights used
		○ Total estimated volume lifted
		○ Session notes (if added)
	• Option to save the session or delete it
	• Option to mark session as a personal best
5. Progress Dashboard
	• Display:
		○ Total rounds completed over time (charts: daily, weekly, monthly)
		○ Heaviest kettlebell weight used
		○ Personal bests (most rounds, heaviest weight)
		○ Current training streak
	• Option to view detailed session history
6. Session History
	• List of all past workouts
	• Filters: date, rounds completed, kettlebell weight
	• Click on individual sessions to view full details
7. Settings / Preferences
	• Set training reminders (frequency, time of day)
	• Adjust target rounds per day/week
	• (Phase 2) Manage user account and cloud sync preferences
8. Optional Future Flows (Phase 2)
	• User authentication and login
	• Social sharing of milestones
	• Multi-device syncing
